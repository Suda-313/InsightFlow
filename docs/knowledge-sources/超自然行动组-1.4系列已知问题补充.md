# 超自然行动组 1.4 系列已知问题补充（KI-1405 至 KI-1408）

> 本文档补充《超自然行动组已知问题与处置指引》中 1.4 系列条目，聚焦 1.4.1/1.4.2 热修涉及编号。与 1.3 系列 KI-1301 **编号不同、根因不同**，检索「机关问题」时需同时加载 map 上下文。

## 使用原则

同主指引：单条玩家反馈不确认问题；需时间窗口内一致症状 + 运营/技术复核。关闭标准同主指引 24h 无高置信新增 + 指标回基线。

## KI-1405：古蜀遗迹机关协作者不同步

### 症状

多人组队进入古蜀遗迹，机关房间协作者计数错误：按钮灰显、无法触发、或提示人数不足。

### 影响范围

- 地图：**古蜀遗迹**（非 1.3 新古迹地图）  
- 模式：四人队、高延迟（>150ms）更高发  
- 版本：1.4.0 起，1.4.2 仍**部分缓解**  

### 版本冲突（必读）

| 来源 | 对 KI-1405 状态 |
|---|---|
| 1.4.1 热修复说明 | 已修复 |
| 1.4.2 热修复说明 | 部分缓解，未关闭 |
| 7 月稳定性说明（7/21） | 已修复（**已被 supersede**） |
| 本文档（7/24+） | 部分缓解 |

**当前生效口径（1.4.2+）：** 未关闭；优先「重新同步」→ 全队重开 → 升级。

### 与 KI-1301 区分

| | KI-1301 | KI-1405 |
|---|---|---|
| 版本 | 1.3.0 | 1.4.0+ |
| 地图 | 1.3 新古迹 | 古蜀遗迹 |
| 根因 | 协作者队列竞态 | 资源缓存 + 心跳丢包 |
| 状态 | 1.3.1 已关 | 部分缓解 |

1.3 公告称 KI-1301 已修**不能**推导古蜀遗迹无问题。

### 临时处置

1. 升级 1.4.2，机关 UI 使用「重新同步」  
2. 清除本地缓存（设置-存储）  
3. 高延迟环境避免四人古蜀排位（7/24～7/31 隔离期）  
4. 无效则全队退出重开  

### 升级条件

30 分钟内 ≥10 条高置信且含版本/map/复现步骤 → P1。

## KI-1406：匹配失败后房间状态残留

- **状态：** 1.4.1 已关闭  
- **症状：** 匹配超时仍显示匹配中  
- **处置：** 1.4.1+ 一般自动恢复；否则退出房间重进  

## KI-1407：结算队列积压（事件型）

- **性质：** 7/19 晚高峰运维事件，非 KI-1403 设计值变更  
- **症状：** 到账 >30 分钟  
- **当前：** 1.4.2 扩容 + 重试后监控 P99 <15 分钟告警  
- **与 KI-1403：** 10 分钟内仍属设计预期；>10 分钟先查是否 7/19 类事件再升级  

## KI-1408：Android 10 Mali-G52 撤离闪退

- **状态：** 1.4.2 已关闭（特效降级）  
- **症状：** 撤离倒计时阶段闪退  
- **处置：** 升级 1.4.2  

## 关闭与归档

KI-1406、KI-1408 已关，转入历史归档。KI-1405、KI-1407 观察中。关闭 KI-1405 前不得引用 1.4.1「已修复」对外承诺。

## 升级工单模板（KI-1405）

必填：版本、地图=古蜀遗迹、队伍人数、RTT 自报、是否已点重新同步、机关房间 ID（截图）。缺 map 字段的工单不得 closure 为 KI-1301。

### KI-1407 与 KI-1403 工单分流

| 等待时长 | 优先编号 |
|---|---|
| ≤10 分钟 | KI-1403 正常口径 |
| 10～30 分钟 | 查是否 7/19 类高峰，可能 KI-1407 |
| >30 分钟 | 升级人工 + 引用 STAB-202607 |
