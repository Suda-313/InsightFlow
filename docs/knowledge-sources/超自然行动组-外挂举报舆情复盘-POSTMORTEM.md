# 超自然行动组外挂举报舆情复盘

> document_type: POSTMORTEM。覆盖 1.3.0 举报优化上线后两周的舆情波动；与 KI-1404、1.3 版本公告形成跨文档引用链。

## 背景

1.3.0（2026-06-12）上线举报禁言与匹配处罚优化。版本公告预判「举报量可能短期上升」。6/12～6/26 实际出现举报相关负面帖 +140%，引发是否「外挂泛滥」的社区争论。

## 时间线

| 日期 | 事件 |
|---|---|
| 6/12 | 1.3.0 发布，举报入口 UI 放大 |
| 6/13～6/15 | 举报类帖 hourly 升 3 倍，外挂关键词共现率 45% |
| 6/15 | 1.3.1 热修无关举报；舆情峰值未降 |
| 6/18 | 内部分析：处罚量 +12%，举报量 +210%——量升≠外挂升 |
| 6/22 | 发布社区说明：治理加强导致举报更方便 |
| 6/26 | 负面占比回落至 1.3 前基线 +8% |

## 根因结论

**主因：** 举报入口曝光 + 玩家预期「提交即处罚」（KI-1404 类预期偏差）。  
**次因：** 6/20 周末新怪物难度上升，失败者更易怀疑对手作弊。  
**否证：** 服务端作弊检出率 6 月与 5 月持平（±2%，内部），不支持「外挂泛滥」。

## 与 1.4 举报文案迭代关系
