# 超自然行动组 1.3.1 热修复说明

> 本文档描述 1.3.0 全量发布后的首个热修复窗口内容；1.4.0 发布后本说明仅作历史对照，当前生效规则以最新版本公告与已知问题指引为准。

## 发布信息

- 版本号：1.3.1
- 热修窗口：2026-06-15 14:00 至 16:00
- 适用范围：正式服全量玩家，无需手动下载安装包（资源热更）
- 前置版本：1.3.0（2026-06-12 发布）
- 运营观察窗口：热修完成后 48 小时

本次热修复针对 1.3.0 上线后 72 小时内集中反馈的两类阻断性问题：新地图机关交互异常、潜伏型怪物 AI 路径卡死。热修不涉及道具数值回滚，也不调整举报治理策略。

## 修复内容

### KI-1301：新地图机关房间偶发无法交互

**现象回顾：** 1.3.0 新增的中式古迹地图内，部分多人协作机关在第二名玩家加入交互圈后，交互按钮灰显且无法再次触发；单人在线测试环境难以复现，需至少两名玩家同时处于机关触发半径内。

**根因说明（对内）：** 机关状态机在「等待协作者」与「可交互」之间的切换存在竞态；当两名玩家几乎同时按下交互键时，服务端只记录了首个请求，第二个请求被静默丢弃，客户端 UI 仍显示「等待中」。

**修复措施：**

1. 机关协作者队列改为 FIFO 顺序确认，第二名玩家加入后 3 秒内必须完成二次确认，否则队列自动释放。
2. 客户端增加「协作者已满/等待中」的明确文案，避免玩家误以为按钮失效。
3. 已在测试服完成 200 局双人/四人混合压测，未再出现交互灰显。

**对外口径：** KI-1301 已于 1.3.1 修复；若玩家仍报告同类现象，先确认客户端版本是否为 1.3.1 及以上，并收集机关所在房间编号与队伍人数。

### KI-1305：潜伏型怪物偶发原地踏步

**现象回顾：** 1.3.0 新增的潜伏型怪物在部分狭窄走廊生成点后，触发现身逻辑但 NavMesh 寻路失败，表现为原地踏步或反复撞墙；玩家反馈「怪物出现了但打不到」。

**修复措施：** 调整潜伏型怪物的最小生成半径校验，若目标 NavMesh 不可达则延迟 5 秒后在备用点重生；不影响怪物伤害与掉落配置。

**问题编号说明：** KI-1305 为 1.3 系列内部编号，未写入 1.4 已知问题指引；若 1.4 版本出现不同编号的同类现象，应新建编号处理。

## 玩家沟通 FAQ

### 热修后还要重新下载吗？

1.3.1 为资源热更，玩家登录时若提示「正在更新资源」属正常，体积约 45MB，与 1.4 全量包无关。若 10 分钟内无进度，切换 Wi-Fi 后重启客户端，仍失败则按网络类问题记录，不归因于 KI-1301。

### 机关修好后古蜀遗迹还会卡吗？

会。1.3 新地图与古蜀遗迹为不同资源分支；1.4 古蜀分支的 KI-1405 与 KI-1301 无继承修复关系。玩家若混淆两地图名称，客服应请其截图地图加载界面标题核对。

### 潜伏型怪物还会原地踏步吗？

1.3.1 已降低 NavMesh 不可达生成概率；若仍遇「现身无伤害」，先排除网络延迟与未命中，再收集固定走廊坐标。同类现象在 1.4 未新建编号，通常不再按 KI-1305 登记。

## 观测指标（内部，不对外报数）

热修后 48 小时值班表要求每小时记录：KI-1301 关键词帖量、协作者队列相关工单、潜伏型「打不到」帖量。三者任一超过 1.3.0 首周峰值的 120% 需同步版本组评估是否二次热修。实际记录显示 6/16 20:00 后三类指标均低于峰值 40%。
