# 运营事件记录模板

> 本文件用于记录版本上线、活动、维护、渠道策略等带时效的运营事实，不描述任何真实事件内容。
> 上传发布前必须替换全部占位字段，不能保留 `{{ }}` 占位符或本说明区块进入正式发布版本。
> 建议文档类型：`OPERATION_EVENT`。

## 使用说明

1. 复制本模板为新文件，文件名建议 `超自然行动组-{事件编号}-运营事件.md`。
2. `effective_from` / `effective_to` 必须对齐事件实际影响窗口；过期事件仍可作为历史调查语料保留，但检索将按适用窗口过滤。
3. `fact_boundary` 必须明确本记录可引用的事实范围（渠道、平台、数据来源），避免 Agent 过度推断。
