# 超自然行动组 1.3 版本更新说明

> 本文档为 1.4 版本发布前的历史版本公告，保留用于版本前后对比和跨文档检索验证；
> 涉及已结束的活动时间窗口，不代表当前生效规则，当前生效规则以最新已发布版本公告为准。

## 发布信息

- 版本号：1.3.0
- 上线窗口：2026-06-12 10:00 至 12:00
- 适用范围：正式服全量玩家
- 运营观察窗口：上线后 72 小时

本次更新聚焦新地图上线、道具平衡性调整和外挂治理，是 1.4 版本“局内协作与结算优化”方向的前置版本。

## 主要调整

### 新地图与新怪物

1. 新增一张中式古迹地图，地图内包含限时开启的隐藏宝藏区域，需要多名玩家协作解开机关后方可进入。
2. 新增一种巡逻型怪物，具备短距离追击和视野内标记能力；玩家可通过烟雾类道具短暂遮蔽视野脱离追击。
3. 新增一种潜伏型怪物，平时不会主动出现，仅在玩家长时间停留同一区域时才会现身，用于抑制“蹲守刷分”打法。

### 道具平衡性调整

1. 支援类道具的冷却时间统一延长 15%，避免单一道具组合过强导致其他道具使用率过低。
2. 进攻类道具对潜伏型怪物的首次命中伤害提升，鼓励玩家主动应对而非长期规避。
3. 探索类道具的宝藏定位范围小幅缩小，弱化“一键找齐”的探索体验。

### 外挂与作弊治理

1. 上线举报功能优化：命中判定后玩家将在本局内直接被禁言，减少对局内其他玩家的持续骚扰。
2. 频繁违规账号将触发匹配层面的封禁处罚，处罚结果不会实时展示给举报人，避免处罚信息被滥用。
3. 治理措施上线后一段时间内，举报量可能短期上升，这是治理生效、举报入口更显眼导致的正常现象，不能直接等同于外挂数量增加。
