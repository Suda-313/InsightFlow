# 超自然行动组玩法机制与舆情判读参考

## 目的与边界

本参考文档面向舆情分析人员和客服，说明《超自然行动组》的核心玩法机制，帮助判断一条反馈是“正常玩法体验”还是“需要排查的故障”。本文档不是玩家攻略，不涉及具体数值强度建议，也不替代《游戏舆情分析与风险分级手册》中的风险判断标准；两者应配合使用，本文档解决“这是设计如此还是故障”，风险手册解决“是否需要升级处理”。

## 核心游戏循环

《超自然行动组》是一款支持单人到四人组队的中式恐怖寻宝题材游戏，核心循环分为三个阶段：

### 搜索阶段

玩家在随机生成的古迹地图中探索，寻找并收集高价值文物类道具；地图内可能包含需要多人协作才能开启的机关或宝藏区域。搜索阶段的“找不到宝藏”“地图太复杂”一类反馈通常属于体验建议，而非故障，除非明确描述了机关卡死、无法交互等具体技术现象。

### 战斗阶段

玩家在探索过程中会随机遭遇怪物，需要利用探索、进攻、支援三类道具组合应对：探索类道具用于侦测和定位，进攻类道具用于反制或击退怪物，支援类道具用于团队协作和生存能力提升。怪物类型包括巡逻型、追击型和潜伏型等，不同类型的应对方式不同，玩家因不熟悉新怪物机制而产生的“太难”“打不过”反馈，通常需要结合上线时间判断是否属于体验适应期。

### 撤离阶段

玩家在收集到目标物资后需要前往指定撤离点安全离开；对局中途死亡或未能撤离通常会影响本局收益。撤离阶段相关的“奖励结算不对”反馈应优先参考已知问题指引中的结算延迟条目，而不是直接归为撤离机制故障。

## 难度体验与真实故障的区分标准

判断一条“太难”“打不过”类反馈是设计体验还是故障，可参考以下线索：

1. 时间线索：反馈集中出现在新内容（新怪物、新地图、新玩法模式）上线后的 1～2 周内，且随时间推移逐渐回落，更倾向于体验适应而非故障。
2. 一致性线索：如果玩家描述的现象高度一致（例如均指向同一交互点无法响应、同一操作必定失败），更倾向于真实故障；如果描述差异较大、更多是主观强度感受，更倾向于设计体验问题。
3. 复现线索：能否提供稳定复现路径（固定操作序列、固定地图/怪物组合）。能稳定复现且非预期设计的，应转入已知问题排查流程，不能仅按体验反馈归档。

不满足故障线索但反馈量确实上升时，应作为设计调优的参考意见记录，而不是升级为已知问题。

## 举报与治理机制说明

游戏内置举报功能，命中判定后违规玩家会在本局内被禁言；频繁违规的账号会触发更严重的匹配处罚。这意味着举报生效后短期内“举报量”本身可能因为入口曝光度提升或治理阶段性上线而出现正常上升，不能把举报量上升直接等同于外挂/作弊行为在增加，需要结合处罚生效前后的实际違规检出率综合判断。
