# 超自然行动组版本更新说明模板

> 本文件是内容团队撰写新版本公告时使用的结构模板，不描述任何真实版本内容。
> 上传发布前必须替换全部占位字段，不能保留 `{{ }}` 占位符或本说明区块进入正式发布版本。

## 使用说明

1. 复制本模板为新文件，文件名遵循 `超自然行动组-{版本号}-版本更新说明.md` 命名规则，与已发布版本保持一致的检索前缀。
2. 按“发布信息 → 游戏背景速览（可选） → 主要调整 → 已知影响与关联问题 → 运营观察要求”顺序填写，不打乱章节顺序，便于 Chunker 按标题切分后保持语义连贯。
3. 每个二级章节控制在可独立回答一个客服问题的粒度；避免把多个不相关调整堆在同一小节，否则会降低该章节对应切片的检索精度。
