# 超自然行动组渠道礼包码异常事件档案

> document_type: OPERATION_EVENT。2026 年 6 月底渠道礼包码批量失效事件；与游戏内版本无直接关联，易在「领不到奖励」类检索中与 KI-1403 混淆。

## 事件概要

| 字段 | 内容 |
|---|---|
| 事件代号 | CHAN-20260625 |
| 影响范围 | 某第三方渠道（代号「Tap 合作包」）专属礼包码 |
| 时间 | 2026-06-25 10:00 发现 ～ 2026-06-28 18:00 修复 |
| 玩家影响 | 约 1.2 万兑换请求失败（内部估算） |
| 严重等级 | P2（不阻断对局，影响渠道拉新） |

## 现象

玩家输入渠道礼包码后提示「兑换码无效或已过期」，但码仍在有效期内且未达单码兑换上限。失败集中在 6/25 上午 10 点后新批次码，旧批次正常。

## 根因

渠道侧回调 URL 在 6/24 晚证书轮换后未同步至游戏兑换网关，导致验签失败；游戏服务端记录为「无效码」，**非玩家输入错误**。

## 处置

1. 6/25 14:00 临时关闭该渠道新码兑换，旧码走人工补发队列。
2. 6/28 18:00 证书与回调修复，开放补领页面至 7/5。
3. 未延长码有效期，仅允许受影响账号补领一次。
