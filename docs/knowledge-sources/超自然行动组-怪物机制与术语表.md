# 超自然行动组怪物机制与术语表

## 文档目的

为运营调查与 RAG 评测提供**稳定术语定义**，帮助区分玩家口语与正式机制名。本文档不随单次热修频繁变更；数值微调见版本公告。

## 怪物分类体系

### 巡逻型（Patrol）

**定义：** 沿固定或半固定路径移动，进入警戒半径后追击玩家。  
**代表：** 1.3 前已有「木偶」；1.3.0 新增高机动巡逻型（社区俗称「灰影」）。  
**术语注意：** 「鬼新娘」在官方文档归类为**追击型**，非巡逻型——勿与木偶混淆。

### 追击型（Chase）

**定义：** 触发后持续追踪直至丢失视野或玩家撤离阶段开始。  
**代表：** 鬼新娘、狐妖。  
**调查线索：** 玩家说「一直追」多为追击型；说「转角遇见」可能是巡逻型或潜伏型。

### 潜伏型（Ambush）

**定义：** 玩家在同一区域停留超过阈值（默认 45 秒）后现身。1.3.0 新增，用于抑制蹲守。  
**关联问题：** KI-1305（NavMesh 卡死）已在 1.3.1 修复；与 KI-1405 机关无关。

## 官方名称 vs 社区俗称

| 官方名 | 常见俗称 | 备注 |
|---|---|---|
| 鬼新娘 | 红盖头、新娘 | 追击型 |
| 狐妖 | 狐狸、三尾 | 追击型，会幻象分身 |
| 木偶 | 机关人、瓷娃 | 巡逻型 |
| 潜伏型（无单独名） | 地缚灵、黑影 | 1.3 新增 |

舆情样本标注应优先写官方名，俗称放括号备注。

## 与道具交互术语

- **烟雾类道具：** 遮蔽视野，用于脱离巡逻/追击；对潜伏型「现身前」无效。
- **进攻类道具：** 首次命中潜伏型有伤害加成（1.3.0 平衡）。
- **支援类道具：** 团队 buff；1.3.0 冷却 +15%。

## 难度 vs 故障（调查引用）

新怪物上线 1～2 周内「太难」反馈上升，若：

- 描述分散（有的说追不到，有的说伤害高）
- 无稳定复现路径  

→ 引用《玩法机制与舆情判读参考》体验适应条款，**不新建 bug 编号**。

若高度一致指向「现身后无敌」「零伤害」→ 升级技术排查。

## 评测题示例

- 单文档：「鬼新娘属于哪类怪物？」→ 追击型  
- 跨文档：「1.3 新怪导致卡死」→ 术语表 + KI-1305 + 1.3.1 热修  
- 拒答：「鬼新娘血量多少」→ 本文档不含数值

## 调查场景示例

### 场景 1：「鬼新娘太难」

新内容上线 10 天内、描述分散、无复现 → 体验建议，引用玩法机制参考，非 KI。

### 场景 2：「木偶穿墙」

多账号同坐标、可录像 → 技术排查，可能新建 KI，勿套用 KI-1305。

### 场景 3：「古蜀里鬼新娘和精绝不一样」

地图变体属设计；若指伤害异常零值 → 查版本与 KI，非术语表范围。

## 索引维护

新增怪物时必须更新「版本引入表」与「官方名 vs 俗称」表，避免 RAG 检索到过时俗称。

## 地图与怪物 spawn 关系

精绝古城以巡逻型、追击型为主；1.3 新古迹增加潜伏型密度；古蜀遗迹为 1.2 地图的 1.4 资源分支，怪物表与精绝不同。玩家说「古城鬼新娘」时需确认地图，避免张冠李戴。
