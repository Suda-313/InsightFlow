# 版本档案模板

> 本文件用于记录某一游戏版本的完整档案（上线背景、变更摘要、关联事件与观察结论），不描述任何真实版本内容。
> 上传发布前必须替换全部占位字段，不能保留 `{{ }}` 占位符或本说明区块进入正式发布版本。
> 建议文档类型：`RELEASE_NOTE` 或 `OPERATION_EVENT`（若侧重时效事实而非公告口径）。

## 使用说明

1. 复制本模板为新文件，文件名建议 `超自然行动组-{版本号}-版本档案.md`。
2. 填写元数据对应字段：`effective_from` / `effective_to` 对齐版本观察窗口；`fact_boundary` 说明本档案可断言的范围。
3. 每个二级章节控制在可独立回答一个调查问题的粒度。
