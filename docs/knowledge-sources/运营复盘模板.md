# 运营复盘模板

> 本文件用于已完成运营/版本/事故事件的证据化复盘，不描述任何真实事件内容。
> 上传发布前必须替换全部占位字段，不能保留 `{{ }}` 占位符或本说明区块进入正式发布版本。
> 建议文档类型：`POSTMORTEM`。

## 使用说明

1. 复制本模板为新文件，文件名建议 `超自然行动组-{事件编号}-复盘.md`。
2. 复盘必须区分「已确认事实」「推测」「不确定项」与「建议动作」，不得把推测写成结论。
3. `fact_boundary` 须说明证据来源与时间范围；不含玩家隐私原文或未脱敏业务数据。
