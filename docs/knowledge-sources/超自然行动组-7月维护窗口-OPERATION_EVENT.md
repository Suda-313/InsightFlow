## 窗口内预期现象（非 bug）

以下现象在维护窗口及开服后 **2 小时内**属预期，**不应登记为新已知问题**：

- 无法登录、排队、连接超时
- 开服后首次下载资源导致「更新后卡加载」（KI-1401 前兆）
- 匹配服务短暂不可用

## 窗口外升级条件
