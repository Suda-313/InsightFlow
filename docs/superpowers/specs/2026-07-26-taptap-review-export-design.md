# TapTap 评论导出脚本设计

## 目标

在主应用之外提供一次性数据采集脚本，通过已获授权的 TapTap 网页评论接口抓取《超自然行动组》（应用 ID：`714123`）最多 1,000 条评论，产出可直接被 InsightFlow 现有 CSV 导入功能使用的数据文件。

脚本服务于 Agent、RAG 与评测的真实数据测试，不是 Spring Boot 运行时能力，也不新增主应用 API、前端页面、数据库迁移或定时任务。

## 范围与边界

- 仅支持 TapTap 评论网页接口和应用 ID `714123`。
- 仅由人工在命令行启动，不做定时采集、常驻进程或增量监控。
- 通过 HTTP 请求接口，不使用浏览器自动化。
- 仅提取评论稳定标识、正文、发布时间、评分和平台；昵称、头像、主页、设备等字段在解析阶段丢弃。
- 采集结果仅保存在 Git 忽略的 `output/` 目录，不将第三方评论正文提交到仓库。
- 任何 Cookie、请求头或授权信息只从本地环境变量读取，禁止写入代码、配置示例、清单或日志。

## 输出契约

脚本输出 UTF-8 CSV，表头固定如下：

```csv
feedback_text,occurred_at,source,external_ref,rating,platform
```

- `feedback_text`：清洗后的评论正文；最终导入仍由主应用的 PII 脱敏器二次处理。
- `occurred_at`：评论接口返回的真实发布时间，转换为 ISO 8601 带时区格式。
- `source`：固定 `taptap_review`。
- `external_ref`：TapTap 评论稳定标识，仅供主应用哈希去重，不对外展示。
- `rating`、`platform`：可选维度，映射到既有导入器的 `dimensions`。

脚本同时输出 JSON 清单，包含采集时间、应用 ID、请求页数、成功条数、重复条数、失败页摘要和 CSV 的 SHA-256。清单不携带正文、Cookie 或用户标识。

## 处理流程

```text
命令行参数 → 读取本地环境变量 → 分页请求 TapTap 评论接口
    → 字段校验与最小化提取 → 按评论 ID 去重 → 写入 checkpoint
    → 达到上限或没有下一页 → 生成 CSV 与清单
```

默认目标为 1,000 条。请求遵守固定低频间隔、超时和有限重试；进程中断后从本地 checkpoint 继续。接口字段缺失、返回非预期结构或连续请求失败时以非零退出码终止，不生成伪成功 CSV。

## 文件布局

```text
tools/taptap-review-exporter/
  export_reviews.py
  requirements.txt
  README.md
  tests/
output/                         # Git 忽略
```

脚本不加入 Maven、Node、Spring 配置或主应用包扫描范围。

## 验证

- 使用固定接口响应夹具测试分页、字段映射、去重、上限、异常响应和 checkpoint 恢复。
- 对生成 CSV 校验表头、UTF-8 编码、无空的四个必填字段以及真实时间格式。
- 以一次低频真实探测验证接口契约；首次正式采集完成后用现有 CSV 上传、映射、导入与看板流程验证结果。

## 非目标

- 不实现其他游戏、其他平台、登录绕过、验证码绕过或反爬对抗。
- 不声明采集样本等同于全量玩家或真实舆情占比。
- 不自动修改主题规则、知识库、告警阈值或 Agent 行为。
