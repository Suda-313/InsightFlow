# Agent 模块局部协作规范

本文件补充根目录和 Java 层 `AGENTS.md`，适用于 `agent/` 及其子包。

## 调查边界

- Agent 只能进行只读调查；告警确认、规则调整、知识库发布、策略修改和任何业务写入都必须生成人工确认请求，不能自行执行。
- Agent 获取业务数据必须经过受控 Tool、Guardrail 和 Trace；新增能力不得绕过 Workspace 隔离、直接执行任意 SQL 或访问未经确认的数据源。
- 所有结论必须区分“已确认事实、推测、不确定项、建议动作”，并附带时间范围、指标值或知识来源；没有充分证据时明确说明无法判断。
- 不允许编造指标、版本事件、用户反馈、引用来源或因果关系来让回答显得完整。

## 记忆、知识与评测

- 会话记忆应以按 Workspace 隔离的会话和消息持久化实现；向量检索只用于获批知识文档的召回，不能替代会话历史。
- 知识检索结果必须携带来源、版本和片段标识；输出引用只能来自实际检索或受控数据查询结果。
- Prompt、模型与检索配置必须有版本；Agent 运行需记录输入摘要、输出、证据、耗时、Token、失败原因和 Trace 标识。
- 调整 Prompt、模型或检索策略前，先新增或更新金标评测用例，并用评测结果比较事实正确性、引用覆盖、幻觉、延迟和成本。
