# 前端局部协作规范

本文件补充根目录 `AGENTS.md`，适用于 `frontend/` 下的 Vue 代码和构建配置。

## 页面与状态

- 使用 Vue 3 Composition API 和现有 Pinia Store；不要为单个页面引入新的全局状态方案。
- 所有业务请求必须基于当前 `workspaceId`，并显式处理加载、空数据和失败状态；不得以默认的 0 或空数组伪装请求失败。
- 前端只使用 API 返回的 `public_id` 或公开字段，不暴露或缓存后端内部主键。
- 新增会话、报告或导入等持久状态时，页面刷新后的恢复逻辑必须由后端数据决定，不能只依赖内存 Store 或 `localStorage`。

## 接口与交付

- 不在组件内复制跨页面通用的请求协议、错误解析或 Workspace 选择逻辑；确有重复且已出现至少两处时，再提取最小共享模块。
- 修改前端行为时，为核心回归点添加自动化测试；至少运行 `npm test` 和 `npm run build`。
- `vite build` 的产物会复制到后端静态目录；需要交付可由 Spring Boot 直接访问的前端时，必须构建并同步资源，不要手工编辑打包文件。
